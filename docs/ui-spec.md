# VLM-Forge 介面規格

依 `GOALS.md` §8 寫成的畫面規劃（設計文件，決議仍以 `GOALS.md` 為準）。改介面先改這份。
對應程式：`web/src/App.tsx`（骨架）、`web/src/pages/{Datasets,Review,Train,Test}.tsx`、`web/src/components/{Canvas,ui}.tsx`。

## 0. 原則與名詞

- 三步與資料集頁的結構見 GOALS §8；檢查是資料集的子畫面（第 4 節），不是獨立的一步。
- 每按一次就存：改了就提示「還沒存」，存了就提示「已存」。
- 名詞：預標（AI 導師）、模型（Moondream）、一致／不一致、未比對、自動通過、抽查、已確認、已修正、丟棄。不出現 judge／teacher／student／triage。
- 顏色：**橘色只代表兩件事**——該按的主動作、畫布上你的答案；目前所在／選中＝中性深灰（`--sel-*`）；警告＝琥珀黃（和品牌橘分開）；藍虛線＝預標、紅＝不一致、綠＝一致／通過、灰＝未比對或已存；focus ring 藍色。
- 字級 20（頁面標題）／16（區塊、題目、卡片名）／14（內文）／13（說明）／12（標籤、數字）；間距 4／8／12／16／24。
- 按鈕：每頁只有一顆橘色主按鈕；同一個去處只留一個入口；鍵盤或滑鼠本來就能做的事不再加按鈕（拖動畫面＝Space／中鍵／右鍵，刪除＝Delete）；kbd 標籤只出現在主按鈕（Enter），其餘按鍵看底部快捷鍵列。
- 數字等寬（裝置、語言、深淺色見 GOALS §8）。

## 2. 進站與名字

第一次開：dialog「你是誰？」，空白不能送；記在瀏覽器。右上可改名。名字出現在每筆紀錄、所有圖的認領標記、run 卡。

## 3. ① 資料集

- 清單＝列表列：前 4 張縮圖、名稱＋狀態 pill（標註中 n/m、還有 N 張要看、全部確認、N 張還沒標、沒有圖、上次標註失敗、標註中斷）、模式與更新時間、看過比例進度條、圖／題／已確認／驗證、›；1280 以下藏數字。
- 新資料集 dialog：名稱必填且不重複（即時檢查）、備註。
- 詳情頁左欄＝圖片格：拖曳區（多張、zip、影片／GIF，下方一行「影片每 [1/2/5/10/30/60] 秒抽一張」）、資料夾路徑（圖片與影片；不存在／含 held-out 拒絕）、縮圖角標（val／不一致數／✓）。加圖 toast 寫「加入 N 張（略過 K 張：已經有或幾乎一樣）」；格子上方提示列有重複圖時多一個「有 K 張幾乎重複 → 選取」，選起來就能移除。點縮圖或「去檢查」進檢查，「← 全部圖片」或 Esc 回來。
- 移除圖：縮圖左上角 ☐（hover 才出現）勾選；選了任一張後點縮圖＝加選／取消，Shift 連選，Esc 取消選取。動作欄主按鈕下出現「已選 N 張」卡（全選、取消選取、N 題其中幾題已確認、「重新標註 N 張…」、「從資料集移除…」，Delete＝移除）；確認 dialog 寫明會換掉／刪掉的題數。重新標註用目前的 AI 導師設定（dialog 列出模式與每張圖都問的物件），標註被擋時按鈕灰掉並寫原因。連同這些圖在此資料集的題一起刪；上傳的原檔沒有別的資料集在用才刪，GB300 資料夾的原檔不動；標註中不能移除。
- 右欄依第 1 節順序：主按鈕（下一步）→ 批次卡 → 「AI 導師可信度」卡 → 「AI 導師設定」區塊 → 「匯出」區塊 → 底部建立時間與刪除（輸入名稱確認）。
- 主按鈕依狀態切換：選照片加進來 → 標註新加的 N 張 → 標註中 n/m → 去檢查（還有 N 張）→ 去訓練；標註被 GPU 擋住時主鈕變「去檢查」，標註狀態退成灰字。
- 批次卡：四階段、進度條、ETA、取消；失敗紅卡附原因；學生沒作答時橘字並繼續。中斷（server 重啟／取消）：紅卡列出「N 張還沒出題 · M 題模型還沒答 · K 題還沒比對」＋「接著跑」；清單 pill「標註中斷，可接著跑」。
- AI 導師設定：三選一（自動／自動＋指定／只指定）、指定題目即時解析（`skill: 內容`，顯示有效題數與看不懂的行號）、「每張圖都問的物件」（預設 person、forklift、helmet；導師沒列出的出一題 0 框 detect，同義詞 worker＝person 不重複出題）、進階（巡檢主題、側重、skill、只抽幾張）。
- 匯出：jsonl＋zip 下載連結。
- 「AI 導師可信度」卡：抽查看了 N/總數、同意／改了、直接同意 %（門檻見 GOALS §5：≥90% 可信、75–90% 多抽、<75% 先別用自動通過的題）＋「只看抽查」。

## 4. 檢查（資料集的子畫面）

- 分流規則見 GOALS §5；一張圖有幾題要看就看幾題。進頁自動取下一張（先不一致、再抽查）；可依資料集篩選；一次一題，只畫這題的框／點；存一題跳下一題，一張看完自動換圖；全部看完→「去訓練」。
- 這張圖的題目清單在動作欄下半（狀態點、題目、一致／不一致／抽查／已存），當前題高亮，點了跳題（未存改動先問）；頂列只剩檔名、「這張還有 N 題」、待看張數。
- 題目卡：狀態、題目大字、比對理由（中文含數字）、格式提示（數量題用數字、是非題 yes/no）。
- 主按鈕隨狀態「沒問題」／「存修正」（Enter；Space 留給拖動畫面）；丟棄（D）；跳過（S，釋放認領）；剩下全存（Shift+Enter，3 秒內可復原）；←/→ 換題、Z 還原這題、G 所有圖、? 說明。Ctrl+Z＝重開上一個存過的題（跨圖；整張全存算一步）；標題列灰字顯示節奏「每題 N 秒 · 剩約 X」（最近的存檔間隔，超過 2 分鐘的停頓不算）。畫面底部常駐一行快捷鍵（只列此題用得到的），按到的鍵亮橘色。
- 圖工具列：縮放、適應（F）、預標顯示切換、H 看原圖；拖動畫面＝Space／中鍵／右鍵。畫布高度跟著圖的長寬比（不留黑邊，最高到視窗底）；換到框／點題時自動縮放到「預標 ∪ 模型」的框（占畫面 70%），F 回全圖。
- 認領：10 分鐘；所有圖 overlay 顯示別人認領中（灰＋名字）。
- ＋加一題（A）：題目清單頂端一行；dialog 選 Detect／Point／Query、輸入物件或問題（Enter 加入），加了就成為這張的待看題並跳到它；同一題已存在則提示。
- 「只看抽查」：檢查頁工具列的切換（和資料集頁可信度卡同一個開關），開啟時只取有抽查題的圖、Enter 只在抽查題之間前進。

### 4.3 detect
拖曳新框、點框選取、拖框移動、拖角縮放、Delete 刪、Tab 選下一框、方向鍵微移（Shift 10px）、1 用預標框、2 用模型框、Z 還原；0 框時若預標或模型有框，提示「確認這張沒有 X？」；超過 12 個實例的物件不出題。

### 4.4 point
點一下加點（點在還沒有點的預標框裡會吸到框中心，按住 Alt 放原位）、拖點移動（點有 24px 抓取範圍、編號、hover 放大）、Delete 刪選取、Backspace 刪最後一點、Tab、方向鍵；**3＝在每個還沒有點的預標框中心補一點**（detect 題的 3＝補上預標有而目前沒有的框）；預標藍框＝物件範圍；一致＝模型的點落在預標框內。

### 4.5 query
題型決定答案元件：是非題（Is/Are/Does…開頭）＝兩顆大鈕 Y／N，按鍵直接存；數量題（How many／count）＝數字框，按數字鍵填、↑↓ 加減、Enter 存；其他＝答案框（E 聚焦、框內 Enter 存、Esc 離開）。都有「1 預標」「2 模型」按鈕、不一致理由「模型「…」vs 預標「…」」。

### 4.6 caption
長文框；judge 標出圖裡沒有的片語做成紅 chips，✕ 直接從文字刪；長度 short/normal/long；一致＝judge 沒挑出片語。

### 4.6b 預標覆蓋與同步
框／點題的預標框一旦被目前答案蓋到（point：框內有點；detect：IoU > 0.3）就變綠 ✓；point 題裡不在任何預標框內的點是紅色。detect 題若同一張圖有同物件、還沒看的 point 題，動作欄出現「存的時候同時存 Point：X（每框中心一點）」（預設開，P 切換），存 detect 就一起存 point，toast 可「復原 point」。

### 4.7 所有圖（G）
篩選：待看／自動通過／已看過／全部；角標＝不一致題數／抽／✓；別人認領中灰掉；已看過可重審。

## 5. ② 訓練

- 版面照工作順序由上而下：**① 選資料集**（卡片，點一下勾選；每張卡顯示確認筆數、圖數、驗證張數、skill 長條；沒有確認題的資料集灰掉並寫原因）→ **② 設定**（名稱、步數、學習率一列，進階收合）→ **訓練紀錄**（目前／最近一次的完整卡在上，下面是歷史列表，點一列換卡）。
- 右欄：主按鈕「開始訓練 名稱」，下面是「這次會訓練」摘要（資料集、筆數／張數、步數與預估時間、會用哪些考卷評分、skill 長條），再下面紅字擋／黃字提醒。
- 名稱自動 ft-MMDD-HHMM；步數、學習率、rank 的預設見 GOALS §6；進階：rank、region head（開了 Orin 載不了）。摘要寫明驗證從哪來（資料集驗證集或從訓練圖切出），沒有時黃字。
- 開始前紅字擋住：0 筆、名稱重複、權重缺、另一個訓練在跑；黃字不擋：有圖沒看、某 skill < 20 筆、region head。
- 執行中：階段、步數進度、ETA、VRAM、loss 曲線（train 實線、val 虛線＋評估點）、取消；完成：核對表 指標｜base｜新｜Δ｜PASS/FAIL；失敗：最後 20 行 log；歷史可刪。

## 6. ③ 測試

- 頁首：狀態 pill（訓練中 N/M 步／N 個模型可比／還沒有模型）；沒有模型時「下一步」卡（訓練中→完成後多一欄；否則→去訓練）。
- 分數：工廠 CCTV（v1 目標考卷）一張全寬主卡在上，驗證集與參考考卷縮成下面一列小卡；卡內小表 skill × [base, 每個 run]；run 欄頭掛過關／沒過與一個「看差異 →」（看差異以模型×考卷為單位）；格＝分數＋Δ pill（綠紅灰）；白話註解（F1／答對率、v1 目標）。
- 看差異：run／考卷／篩選（只看變化／變好／變差／全部）；空間題並排兩張疊圖（正解虛線），**兩張同步縮放與拖動**；文字題三行＋diff；←/→ 換題；試一張的並排圖同樣同步。
- 試一張：進頁自動選最近一張圖；四個 skill；巡檢快問 chips（值班／安全帽／背心／出口／地面／堆高機數、detect person/forklift/helmet…）；Enter 執行；結果列 pill「base · 3 框 · 420 ms」「新模型 · …」；可「存成資料集的題」。
- 分數是主畫面；看差異、試一張是子畫面（← 分數／Esc 回來）。
- 匯出到 Orin：分數頁右欄的可收合區塊——選模型、Photon 相容 pill、下載 adapter 包（adapter.pt、local_adapter.py、README、bench_orin.py、scores.json）、「Orin 上怎麼用」展開範例（`local_adapter.Tuned`；官方 client 的 adapter 只認雲端 id，包裡自附 kestrel AdapterProvider）。

## 8. 多人

名字必填；每筆記 reviewer＋時間；取圖鎖 10 分鐘，跳過即釋放；兩人同存後者覆蓋。不做帳號、權限、指派。

## 9. 邊界

大圖用 2048px 副本與 200px 縮圖，座標 0–1；重複圖以 sha 判斷；取消／重啟保留已出的題；權重或出題模型缺時 pill 常駐、相關按鈕灰掉；GPU 被別的訓練佔住時出題模型載不了（32B 需約 70 GB；有下載 8B 時門檻降到 22 GB，系統 pill 琥珀「用 8B 出題」），錯誤直接寫明剩多少；預標超過 12 個實例不出題；壞 JSON 修復或略過；held-out 不能進資料集。
